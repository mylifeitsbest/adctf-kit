## ЗОЛОТЫЕ ПРАВИЛА (прочитать всем, один раз)

1. **Очки = аптайм + атака − потери флагов.** Главная задача не «взломать всех», а **не лежать и не отдавать флаги**. Упавший сервис (SLA красный) съедает очки сильнее, чем пара непойманных атак.
2. **С первой минуты (10:00) включите tcpdump на vulnbox.** Это ваш самый главный инструмент: по дампам вы 1) находите, кто вас ломает и как → патчите; 2) **воруете чужой эксплойт и реплеите его против всех**. Неподготовленная команда так и набирает атаку. См. [05_traffic.md](05_traffic.md).
3. **Бэкап каждого сервиса ДО открытия сети** (10:00–10:40). Железо физическое, перезалить нельзя. Сломал патчем — откатился. См. [01_hardening.md](01_hardening.md).
4. **Патч, не блокировка.** Jury/чекер ходит с того же IP-диапазона, что и атакующие, забанить атакующего не забанив чекер почти нельзя → сервис уйдёт в красный. Фильтры — тонкий инструмент, основа защиты = фикс уязвимости в коде.
5. **НЕ трогай флаги в хранилище и формат ответов чекера.** Если «починишь» так, что чекер перестал класть/читать флаг — SLA красный, минус очки. После каждого патча смотри, что чекер зелёный.
6. **Флаг живёт 5 раундов.** Перезапустил сервис с нуля → пара раундов можешь не находить старые флаги, ферма будет ругаться. Это нормально, планируй рестарты.
7. **attack_data — твои цели.** Чекер сам кладёт flag_id (какого юзера/какую записку доставать). Не угадывай юзернеймы — бери их из attack_data. См. [03_farm_submit.md](03_farm_submit.md).
8. **Своя машина = крепость.** Смени пароль, выключи парольный SSH, снеси чужие ключи — ДО открытия сети, иначе соседи зайдут и всё снесут (резерва нет). См. [01_hardening.md](01_hardening.md).
9. **Интернета нет.** Всё, что нужно (ферма, шаблоны, этот гайд), затащи на игру заранее — положи в **публичный GitHub-репозиторий** и клонируй на боевой машине (GET разрешён). Внешние диски нельзя.
10. **Коммуникация.** Нашёл уязвимость / получил эксплойт / патчишь сервис X — сразу говори команде вслух. Два человека не должны чинить одно и то же.

## ТАЙМЛАЙН ЗАВТРА

| Время | Что происходит | Что делаем |
|------|----------------|-----------|
| 08:xx | Завтрак | Поели быстро — больше времени на настройку |
| 09:00–10:00 | Садимся за Kali-ноуты | Ставим софт, ставим доверенный сертификат (скрипт по URL `/serp`), проверяем что система/прокси работает, клонируем свой репо-гайд |
| **10:00** | Выдают vulnbox (Ubuntu), **сеть закрыта 40 мин** | СРАЗУ: сменить пароль, SSH-ключи, **бэкап всех сервисов**, запустить tcpdump, аудит портов, закрыть лишнее |
| **10:40** | Сеть открывается | Защита рабочая → начинаем копать сервисы и атаковать |
| ~13:00 | Общий обед 1 час, **сеть закрыта** | Едим, обсуждаем стратегию между собой |
| 14:00 | Продолжение, сеть открыта | Атака на полную, патчим по дампам |
| ~16:30 | Скорборд замораживают | Держим аптайм, не роняем сервисы |
| **17:00** | Конец | — |

> Проверь реальные тайминги по месту — выше по словам с открытия.
