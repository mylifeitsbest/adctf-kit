## ЗОЛОТЫЕ ПРАВИЛА
1. **Очки = аптайм + атака − потери флагов.** Главное — не лежать и не отдавать флаги.
2. **tcpdump с 10:00** — воруем чужие эксплойты из дампа.
3. **Бэкап всего ДО открытия сети** (железо, отката нет).
4. **Патч, не блокировка** (бан убьёт чекер).
5. **Флаг живёт 5 раундов** — сдавай свежие сразу.
6. **attack_data — твои цели**, бери flag_id оттуда.
7. **Своя машина = крепость**: смени пароль, выключи парольный SSH, снеси чужие ключи.
8. **Всё говорим вслух**: нашёл баг / патчу X / ферма сдаёт.
